# NutriDesk — atualizações

Este repositório publica apenas os **instaladores** do NutriDesk e o arquivo `latest.json` usado pela atualização automática do aplicativo. O código-fonte é privado.

- Baixe a versão mais recente em [Releases](https://github.com/kaykefreitas0dev-cmd/nutridesk-atualizacoes/releases/latest).
- Os pacotes de atualização são assinados: o aplicativo só instala atualizações com assinatura válida.
- O uso do NutriDesk é gratuito por 30 dias; depois, é preciso uma licença.
